# SciDiagnose v0.2 Progress Report

## Environment

- Local Python: Anaconda Python (LangGraph dependency environment)
- LangGraph: 1.2.11; checkpointer: `langgraph.checkpoint.memory.InMemorySaver`
- Remote host: `ubuntu` via SSH Direct
- Remote runtime: `~/venvs/scidiag/bin/python`, NumPy 2.5.2
- Model: configured school OpenAI-compatible API (model name intentionally not recorded)

## Architecture implemented

- LangGraph nodes: `observe → hypothesize → plan → execute → evidence → reflect → finalize`.
- Explicit `DiagnosisGraphState`, `Hypothesis`, and `EvidenceItem` state objects, including reserved `knowledge_queries` and `knowledge_evidence` fields for v0.3.
- Existing SSH Direct backend and structured remote result protocol are reused.
- New composable `evaluate_candidate` supports pipelines of transforms and non-wrapping shifts.

## Real runs

### B01 single-fault graph run

- Run: `runs/RUN_B01_SINGLE/`
- Backend: SSH Direct / `ubuntu`
- Remote experiments: 2
- Outcome: validated `rot180` candidate; final agreement exceeded threshold.

### P1 pipeline smoke

- Real `rot180` candidate: agreement 1.0 on legacy GEO-001 regression input.
- Real `rot180 + shift` candidate: valid-pixel metrics returned, confirming non-wrapping masking reaches the remote result schema.

## Cases

- B01: single transform fault; generated and tested.
- B03: no-fault clean baseline generated at approximately 0.936 agreement.
- B02: compound transform-plus-shift generator is accepted after adding public `target_valid.npy` metadata. Real remote validation: initial agreement 0.5733, `rot180` only 0.7440, and `rot180 + shift(-5,+5)` 0.9719 with valid fraction 0.9613.

## Failures encountered

- School model occasionally returned alternative action envelopes; v0.1 compatibility normalization was extended.
- Intermittent Windows SSH sessions required independent short connections and retryable status polling.
- B02 revealed that non-wrapping injected shifts need an explicit recoverable validity-mask design. This was resolved through public valid-pixel metadata, which is transformed with each candidate pipeline.

## Tests

`8 passed` locally, covering legacy generation/model parsing plus pipeline order, non-wrapping shift, and v0.2 generator baseline properties.

## Current limitations

- Real model replanning on B02 remains incomplete; the compound pipeline itself is validated.
- Hypothesis node is currently a minimal explicit state initializer; it still needs the planned structured LLM hypothesis updater.
- Only 2-D synthetic spatial experiments are implemented.
- No RAG, temporal reasoning, real satellite product data, or compute router is implemented.

## Next stage

v0.3 will add Knowledge-Grounded Scientific Diagnosis, combining experimental and retrieved scientific knowledge evidence.
